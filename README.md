# KiCad-Library

This library houses all the components used in incutec products.

## Usage

Either place the library parallel to the other incutec repos:

```
OpenDrone/
├─ OpenRX/
│  ├─ archive/
│  ├─ ...
├─ OpenFC/
│  ├─ hardware/
│  ├─ ...
├─ ...
├─ KiCad-Library/
```

or include the respective parts globally in your KiCad installation:

`Main Window -> Manage Symbol Libraries -> Global Libraries -> Add existing (the folder icon at the bottom) -> Browse to Incutec.kicad_sym`

## Current state of development

This library is in its infancy. Don't expect completeness, don't expect that all parts of all hardware are already here. But new stuff will from now on only appear here. It already includes some symbols, but footprints will also come.
